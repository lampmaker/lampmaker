## Hi, I'm Matthijs 👋

I have worked with light for about thirty years: LED systems, nonimaging optics, photobiological safety, and taking
hardware to production at Philips, Lumileds and my own companies, with 25+ patents along the way.

I think good optical tools shouldn't need an expensive licence and a workstation to get started. So I'm building one
that runs in a browser.

### [ShadyTracer](https://github.com/lampmaker/ShadyTracer)

**Physically based light in the browser.** A WebGPU path tracer that renders in real units, candela per square metre
and lux, with a scene builder, a measuring tool, and an optics bench for LED and luminaire design that traces the same
scene the picture shows. Nothing to install: it runs on your own graphics card.

**[Run it →](https://lampmaker.github.io/ShadyTracer/)**

### Also here

- **[tinywebgpu](https://github.com/lampmaker/tinywebgpu)**: one file, no dependencies, no build step. A WebGPU
  micro-framework for shader-first work (SDF tracers, GPGPU experiments, shadertoy-style pieces). ShadyTracer runs on
  it.
- **[GUISTUFF](https://github.com/lampmaker/GUISTUFF)**: UI widgets built on [Tweakpane](https://cocopon.github.io/tweakpane/):
  a property table, a tree view and a split-pane container. ShadyTracer's property table is one of them.
- **[CODEANDWOOD-TOOLKIT](https://github.com/lampmaker/CODEANDWOOD-TOOLKIT)**: the code+wood toolkit, JavaScript
  utilities for arrays, colour, SVG and paths.
